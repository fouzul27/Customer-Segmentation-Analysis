# Customer Segmentation Analysis

## Project Overview

This project uses K-Means Clustering to segment customers based on their annual income and spending behavior. The objective is to identify distinct customer groups and provide business recommendations for targeted marketing strategies.

## Tools Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib
* Power BI

## Dataset

The dataset contains customer information including:

* Customer ID
* Gender
* Age
* Annual Income
* Spending Score

## Machine Learning

### Algorithm Used

K-Means Clustering

### Features Used

* Annual Income (k$)
* Spending Score (1-100)

### Result

Customers were segmented into 5 distinct groups based on spending patterns and income levels.

## Dashboard Pages

### Customer Overview

### Customer Segments

* Cluster Distribution

* Average Spending Score by Cluster

### Business Insights

* Customer Segment Analysis
* Marketing Recommendations

## Key Insights

* Premium customers have high income and high spending behavior.
* Rich but careful shoppers have high income but low spending.
* Budget customers show low income and low spending patterns.
* Targeted marketing can improve customer retention and sales.
